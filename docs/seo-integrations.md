# SEO Integrations

## Present

- GA4 ID is configured in `src/app/layout.tsx` with booking, phone, and email click events.
- Sitemap and robots files are generated by `next-sitemap` during postbuild.

## Not Connected in This Repository

- Google Search Console
- GA4 reporting/export API
- Bing Webmaster Tools / Bing AI Performance
- PageSpeed Insights API
- Crawl/server log exports
- AI citation monitoring provider

Do not commit API keys, service-account files, OAuth tokens, or raw patient/contact data. Preferred inputs are read-only connectors or sanitized CSV exports. Record the export date, property, date range, timezone, and filters with every dataset.
